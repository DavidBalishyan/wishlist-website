05 / Local development

Run it on your machine.

The repository pins Node.js 24.18.0 in .nvmrc and prepares pnpm 11.13.0 in the documented bootstrap sequence. Expo SDK 54 requires Node.js 20.19.x or newer.

Expo’s terminal shows a QR code and shortcuts after startup: a for Android, i for iOS, or w for web. The iOS native target requires macOS with Xcode; Android emulation requires Android Studio. Use the tunnel script when a device cannot reach the local server over Wi-Fi.

Angular delivery layer

This documentation site is separate from the Expo app. Its pages are lazy-loaded Angular components; Tailwind CSS supplies the visual tokens and responsive layout. State is only introduced where it has a job, such as the copy interaction above. The diagram remains code-native inline SVG so it scales without an external image dependency.
